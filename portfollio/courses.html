Python Programming

Database Systems
Introduced the design and implementation of modern database systems used in web, mobile, and cloud applications. Covered relational databases, relational algebra, SQL queries, and database design principles such as normalization and dependencies. Computer Systems
Explored how computer hardware and software interact at the system level. Topics included instruction set architecture, CPU and memory organization, machine and assembly language programming, and basic networking concepts. The course provided insight into how operating systems and low-level hardware support higher-level programs.

Adv Data Structures/Algo Dev
Examined the design and analysis of complex data structures and algorithms. Students implemented structures such as heaps, trees, and graphs while analyzing algorithm efficiency using complexity analysis. The course focused on building scalable and optimized solutions to computational problems.
