Dijkstra Shortest Path Project

A C++ implementation of Dijkstra’s algorithm used to calculate the shortest paths between nodes in two different town graphs. The program represents roads as weighted edges and determines the minimum distance from a starting node to all other nodes while also reconstructing the full path taken.
